# 创建 Docker 账户


你可以使用邮箱地址注册免费的 Docker 账户，也可以通过 Google 或 GitHub 账户注册。创建唯一的 Docker ID 后，你就可以访问 Docker 产品，包括 Docker Hub、Docker Desktop 和 Docker Scout。

你的 Docker ID 将成为你在托管 Docker 服务以及 [Docker 论坛](https://forums.docker.com/) 中的用户名。

> [!TIP]
>
> 请参阅
> [Docker 的订阅计划](https://www.docker.com/pricing?ref=Docs&refAction=DocsCreateAccount)
> 了解可用的套餐。

## 创建并验证你的账户

使用邮箱地址、Google 或 GitHub 注册都需要在登录前完成验证：

- 如果你使用 Google 或 GitHub 注册，请先通过该提供商验证你的邮箱地址。
- 如果你使用邮箱地址注册，Docker 会发送一个一次性密码
  (OTP)。在 OTP 页面输入 Docker 邮件中的验证码。

Docker 会阻止登录，直到你验证完账户为止。

**Email**



1. 访问 [Docker 注册页面](https://app.docker.com/signup/) 并输入一个
   唯一、有效的邮箱地址。
1. 输入一个用作 Docker ID 的用户名。创建 Docker ID 后，你无法更改它，
   如果停用此账户也无法再次使用。你的用户名：
   - 长度必须在 4 到 30 个字符之间
   - 只能包含数字和小写字母
1. 选择一个至少 9 个字符长的密码，然后选择
   **Sign up**（注册）。
1. 收到 Docker 的 OTP 验证邮件后验证你的邮箱地址。这样就完成了注册流程。

**Google or GitHub**



1. 访问 [Docker 注册页面](https://app.docker.com/signup/)。
1. 选择你的社交账户提供商，Google 或 GitHub。
1. 选择你要关联到 Docker 账户的社交账户。
1. 选择 **Authorize Docker**（授权 Docker）以允许 Docker 访问你的社交账户
   信息。Docker 会将你重定向到注册页面。
1. 输入一个用作 Docker ID 的用户名。创建 Docker ID 后，你无法更改它，
   如果停用此账户也无法再次使用。你的用户名：
   - 长度必须在 4 到 30 个字符之间
   - 只能包含数字和小写字母
1. 选择 **Sign up**（注册）。



## 故障排除

如果你拥有付费的 Docker 订阅，请[联系支持团队](https://hub.docker.com/support/contact/) 获取帮助。

所有 Docker 用户都可以通过以下资源寻求故障排除信息和支持，Docker 或社区会尽力提供响应：

- [Docker 社区论坛](https://forums.docker.com/)
- [Docker 社区 Slack](https://dockr.ly/comm-slack)
