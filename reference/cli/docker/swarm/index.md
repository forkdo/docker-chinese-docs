# docker swarm

**Description:** Manage Swarm

**Usage:** `docker swarm`








**Orchestrator:** Swarm

## Description

Manage the swarm.






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker swarm ca`](/reference/cli/docker/swarm/ca/) | Display and rotate the root CA |
| [`docker swarm init`](/reference/cli/docker/swarm/init/) | Initialize a swarm |
| [`docker swarm join`](/reference/cli/docker/swarm/join/) | Join a swarm as a node and/or manager |
| [`docker swarm join-token`](/reference/cli/docker/swarm/join-token/) | Manage join tokens |
| [`docker swarm leave`](/reference/cli/docker/swarm/leave/) | Leave the swarm |
| [`docker swarm unlock`](/reference/cli/docker/swarm/unlock/) | Unlock swarm |
| [`docker swarm unlock-key`](/reference/cli/docker/swarm/unlock-key/) | Manage the unlock key |
| [`docker swarm update`](/reference/cli/docker/swarm/update/) | Update the swarm |
