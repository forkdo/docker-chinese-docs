# docker node

**Description:** Manage Swarm nodes

**Usage:** `docker node`








**Orchestrator:** Swarm

## Description

Manage nodes.






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker node demote`](/reference/cli/docker/node/demote/) | Demote one or more nodes from manager in the swarm |
| [`docker node inspect`](/reference/cli/docker/node/inspect/) | Display detailed information on one or more nodes |
| [`docker node ls`](/reference/cli/docker/node/ls/) | List nodes in the swarm |
| [`docker node promote`](/reference/cli/docker/node/promote/) | Promote one or more nodes to manager in the swarm |
| [`docker node ps`](/reference/cli/docker/node/ps/) | List tasks running on one or more nodes, defaults to current node |
| [`docker node rm`](/reference/cli/docker/node/rm/) | Remove one or more nodes from the swarm |
| [`docker node update`](/reference/cli/docker/node/update/) | Update a node |
