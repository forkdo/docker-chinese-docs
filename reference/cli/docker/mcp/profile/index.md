## Description

Manage profiles

| [`docker mcp profile remove`](/reference/cli/docker/mcp/profile/remove/) | Remove a profile |
| [`docker mcp profile server`](/reference/cli/docker/mcp/profile/server/) | Manage servers in profiles |
| [`docker mcp profile show`](/reference/cli/docker/mcp/profile/show/) | Show profile |
| [`docker mcp profile tools`](/reference/cli/docker/mcp/profile/tools/) | Manage tool allowlist for servers in a profile |
