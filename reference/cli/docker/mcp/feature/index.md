## Description

Manage experimental features for Docker MCP Gateway.

Features are stored in your Docker configuration file (~/.docker/config.json)
and control optional functionality that may change in future versions.






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker mcp feature disable`](/reference/cli/docker/mcp/feature/feature_disable/) | Disable an experimental feature |
| [`docker mcp feature enable`](/reference/cli/docker/mcp/feature/feature_enable/) | Enable an experimental feature |
| [`docker mcp feature ls`](/reference/cli/docker/mcp/feature/feature_ls/) | List all available features and their status |
