# docker buildx history

**Description:** Commands to work on build records

**Usage:** `docker buildx history`










## Description

Commands to work on build records






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker buildx history export`](/reference/cli/docker/buildx/history/export/) | Export build records into Docker Desktop bundle |
| [`docker buildx history import`](/reference/cli/docker/buildx/history/import/) | Import build records into Docker Desktop |
| [`docker buildx history inspect`](/reference/cli/docker/buildx/history/inspect/) | Inspect a build record |
| [`docker buildx history logs`](/reference/cli/docker/buildx/history/logs/) | Print the logs of a build record |
| [`docker buildx history ls`](/reference/cli/docker/buildx/history/ls/) | List build records |
| [`docker buildx history open`](/reference/cli/docker/buildx/history/open/) | Open a build record in Docker Desktop |
| [`docker buildx history rm`](/reference/cli/docker/buildx/history/rm/) | Remove build records |
| [`docker buildx history trace`](/reference/cli/docker/buildx/history/trace/) | Show the OpenTelemetry trace of a build record |
