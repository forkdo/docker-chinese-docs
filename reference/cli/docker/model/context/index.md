# docker model context

**Description:** Manage Docker Model Runner contexts












## Description

Manage Docker Model Runner contexts






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker model context create`](/reference/cli/docker/model/context/create/) | Create a named Model Runner context |
| [`docker model context inspect`](/reference/cli/docker/model/context/inspect/) | Display detailed information about one or more contexts |
| [`docker model context ls`](/reference/cli/docker/model/context/ls/) | List Model Runner contexts |
| [`docker model context rm`](/reference/cli/docker/model/context/rm/) | Remove one or more Model Runner contexts |
| [`docker model context use`](/reference/cli/docker/model/context/use/) | Set the active Model Runner context |
