# docker dhi customization build

**Description:** Manage customization builds












## Description

Commands to manage Docker Hardened Images customization builds






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker dhi customization build get`](/reference/cli/docker/dhi/customization/build/get/) | Get details of a build |
| [`docker dhi customization build list`](/reference/cli/docker/dhi/customization/build/list/) | List builds of a customization |
| [`docker dhi customization build logs`](/reference/cli/docker/dhi/customization/build/logs/) | Get logs of a build |
