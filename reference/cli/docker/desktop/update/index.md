**Description:** Manage Docker Desktop updates

**Usage:** `docker desktop update [OPTIONS]`















## Options

| Option | Default | Description |
|--------|---------|-------------|
| `-k`, `--check-only` |  |  Check for updates without applying them |
| `-q`, `--quiet` |  |  Quietly check and apply updates |
