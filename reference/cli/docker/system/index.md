# docker system

**Description:** Manage Docker

**Usage:** `docker system`










## Description

Manage Docker.






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker system df`](/reference/cli/docker/system/df/) | Show docker disk usage |
| [`docker system events`](/reference/cli/docker/system/events/) | Get real time events from the server |
| [`docker system info`](/reference/cli/docker/system/info/) | Display system-wide information |
| [`docker system prune`](/reference/cli/docker/system/prune/) | Remove unused data |
