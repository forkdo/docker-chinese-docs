# docker volume

**Description:** Manage volumes

**Usage:** `docker volume COMMAND`










## Description

Manage volumes. You can use subcommands to create, inspect, list, remove, or
prune volumes.






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker volume create`](/reference/cli/docker/volume/create/) | Create a volume |
| [`docker volume inspect`](/reference/cli/docker/volume/inspect/) | Display detailed information on one or more volumes |
| [`docker volume ls`](/reference/cli/docker/volume/ls/) | List volumes |
| [`docker volume prune`](/reference/cli/docker/volume/prune/) | Remove unused local volumes |
| [`docker volume rm`](/reference/cli/docker/volume/rm/) | Remove one or more volumes |
| [`docker volume update`](/reference/cli/docker/volume/update/) | Update a volume (cluster volumes only) |
