# docker config

**Description:** Manage Swarm configs

**Usage:** `docker config`








**Orchestrator:** Swarm

## Description

Manage configs.






## Subcommands

| Command | Description |
|---------|-------------|
| [`docker config create`](/reference/cli/docker/config/create/) | Create a config from a file or STDIN |
| [`docker config inspect`](/reference/cli/docker/config/inspect/) | Display detailed information on one or more configs |
| [`docker config ls`](/reference/cli/docker/config/ls/) | List configs |
| [`docker config rm`](/reference/cli/docker/config/rm/) | Remove one or more configs |
