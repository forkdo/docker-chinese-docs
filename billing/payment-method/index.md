# 添加或更新支付方式


Docker 为付费的个人账户和组织提供多种支付方式。本页介绍支持的支付类型、如何在 [Docker Home](https://app.docker.com/) 中管理支付，以及如何设置发票付款。

## 支持的支付类型

您可以随时添加或更新支付方式。所有费用均以美元 (USD) 计价。Docker 支持以下支付方式：

| 类别       | 支付类型                                                   |
| ---------- | ---------------------------------------------------------- |
| 银行卡     | Visa、MasterCard、American Express、Discover、JCB、Diners、UnionPay |
| 电子钱包   | Stripe Link                                                |
| 银行账户   | 使用已验证的美国银行账户进行自动清算所 (ACH) 转账          |

某些支付方式在设为默认支付方式之前需要额外设置。例如：

- 在将银行账户选为支付方式之前，请先[验证该账户](#verify-a-bank-account)。
- 使用已有的 Stripe Link 账户，或输入您的银行卡信息以设置 Stripe Link。

## 管理支付方式

付费的个人账户和组织添加、更新或移除支付方式的步骤相同。

### 添加支付方式

您可以在计费门户中添加多个支付方式。添加新支付方式时，可将其设为新的默认支付方式。

1. 登录 [Docker Home](https://app.docker.com/)。
2. 对于个人账户，请选择您的用户名；对于组织，请选择您的组织名称。
3. 选择 **Billing**（账单）进入计费门户，然后在 **Payment method**（支付方式）磁贴中选择 **Change**（更改）。
4. 在 **Change payment method**（更改支付方式）对话框中，选择添加银行卡、美国银行账户或 Stripe Link 支付。
   - 使用银行卡支付：输入您的银行卡信息。
   - 使用美国银行账户支付：验证您的 **Email**（电子邮箱）和 **Full name**（全名）。
     - 如果您的银行在列表中，请选择银行名称。
     - 如果您的银行不在列表中，请选择 **Search for your bank**（搜索您的银行）。
   - 通过 Stripe Link 支付：选择已有的支付方式，然后选择 **Use this card**（使用此卡）。
5. 首次设置时，请输入您的账单信息。
6. 选择 **Save as default**（保存为默认）完成添加。

### 更改默认支付方式

添加一个或多个支付方式后，您可以将其中一个设为默认方式。

1. 在 **Billing**（账单）中，进入 **Payment method**（支付方式）磁贴。
2. 选择 **Change**（更改）打开 **Change payment method**（更改支付方式）对话框，然后选择当前默认方式旁边的 **Change**（更改）。
3. 选择您想要设为默认的支付方式。
4. 核对您的信息，然后选择 **Save as default**（保存为默认）。

### 移除支付方式

您只能移除次要支付方式。要移除次要支付方式：

1. 在 **Billing**（账单）中，进入 **Payment method**（支付方式）磁贴。
2. 选择 **Change**（更改）打开 **Change payment method**（更改支付方式）对话框。
3. 选择要移除的支付方式旁边的 **Actions**（操作）菜单，然后选择 **Remove**（移除）。
4. 核对您的账单信息，然后选择 **Save as default**（保存为默认）。

您无法移除默认支付方式。如果要移除默认支付方式，必须先更改默认支付方式，再按照移除支付方式的步骤操作。

## 验证银行账户

对于受支持的银行，您可以使用即时验证来验证银行账户。在将银行添加为支付方式时，您必须登录您的美国银行账户：

1. 在 **Billing**（账单）中，进入 **Payment method**（支付方式）磁贴并选择 **Change**（更改）。
2. 选择 **US bank account**（美国银行账户）作为支付方式。
3. 验证您的 **Email**（电子邮箱）和 **Full name**（全名）。
4. 搜索您的银行，然后选择它以启动登录流程。
5. 查看条款和条件。此协议允许 Docker 从您连接的银行账户扣款。
6. 选择 **Agree and continue**（同意并继续）。
7. 选择要链接并验证的账户，然后选择 **Connect account**（连接账户）。

账户验证成功后，会出现一条成功消息。

## 支付失败

如果您的支付失败，请选择 **Pay now**（立即付款）通过 Stripe 重试付款。

支付失败时，您有 15 天的宽限期（包括到期日）。Docker 会按照以下时间表尝试扣款 3 次：

- 到期日后 3 天
- 上一次尝试后 5 天
- 上一次尝试后 7 天

每次支付尝试失败后，Docker 还会发送一封主题为 `Action Required - Credit Card Payment Failed`（需要操作 - 信用卡支付失败）的电子邮件通知，并附上未付发票。

如果宽限期结束后发票仍未支付，订阅将降级为免费订阅，所有付费功能将被禁用。

## 发票付款

> [!TIP]
>
> 要使用发票付款，请[升级到 Docker Team 或 Docker Business 套餐](https://www.docker.com/pricing?ref=Docs&refAction=DocsBillingPaymentMethod)并选择年度订阅。

通过发票付款要求在第一个订阅周期使用支付卡或 ACH 银行转账预先付款。续订时，Docker 会向您发送一封发票邮件，让您手动支付，而不是从您的默认支付方式扣款。

- 要将发票付款添加为一种支付方式，请联系您的 Docker 销售代表。
- 您只能在订阅 Docker Team 或 Docker Business 套餐时选择发票付款作为支付方式。
- 发票付款不适用于订阅升级或变更。
