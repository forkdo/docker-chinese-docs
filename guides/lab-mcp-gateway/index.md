# 实验：Docker MCP Gateway


本实验全面、动手地介绍 Docker MCP Gateway，
它让你能够安全可靠地运行容器化的 MCP 服务器。学习
如何配置、保护 MCP 服务器，并将其连接到你的智能体应用。

## 你将学到什么

- 了解 Docker MCP Gateway 及其架构
- 使用一个简单的 MCP 服务器运行 MCP Gateway
- 安全地向 MCP 服务器注入密钥
- 过滤工具以减少噪音、节省 token
- 使用主流智能体框架将 MCP Gateway 接入你的应用
- 配置并使用自定义 MCP 服务器
