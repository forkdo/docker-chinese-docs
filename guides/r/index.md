本 R 语言专属指南将指导您如何使用 Docker 容器化 R 应用程序。通过本指南，您将学习如何：

- 容器化并运行 R 应用程序
- 使用容器搭建本地 R 应用程序开发环境
- 使用 GitHub Actions 为容器化 R 应用程序配置 CI/CD 流水线
- 将容器化的 R 应用程序部署到本地 Kubernetes 进行测试和调试

首先，让我们从容器化现有 R 应用程序开始。
