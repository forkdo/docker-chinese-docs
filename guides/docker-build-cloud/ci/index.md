Docker Build Cloud 可以显著缩短 CI 构建所需的时间，从而为您节省时间和金钱。

由于构建在远程运行，您的 CI 运行器仍然可以使用 Docker 工具 CLI，而无需提升权限，从而使您的构建默认更加安全。

在本演示中，您将看到：

- 如何将 Docker Build Cloud 集成到各种 CI 平台中
- 如何在 GitHub Actions 中使用 Docker Build Cloud 构建多架构镜像
- 使用 Docker Build Cloud 的工作流与原生运行的工作流之间的速度差异
- 如何在 GitLab Pipeline 中使用 Docker Build Cloud
