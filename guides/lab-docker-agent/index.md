智能体概念，然后构建能够处理复杂现实任务的高级多智能体团队。学习如何使用
Docker 创建、共享并编排 AI 智能体。

## 你将学到什么

- 使用 Docker Agent 创建简单的智能体
- 使用内置的通用智能体工具处理常见任务
- 集成来自 MCP Toolkit 的 MCP 服务器
- 使用 Docker Registry 共享智能体
- 为复杂工作流构建多智能体系统
- 将 Docker Model Runner 与 Docker Agent 配合使用（预览版）

| 7 | 结语 | 总结与后续步骤 |
