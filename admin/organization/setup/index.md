# 设置你的组织


在管理成员和访问权限之前，请先设置你的 Docker 组织。你可以创建一个组织、将其入驻并保护、更新其信息，或将现有的用户账户转换为组织。

## 设置你的组织

你从 [Docker Home](https://app.docker.com) 设置你的组织，并且必须被分配
[组织所有者角色](/manuals/enterprise/security/roles-and-permissions/_index.md)。组织设置大致分为几个阶段：

1. 你可以创建一个新组织，或将现有的用户账户转换为组织。选择适合你当前使用 Docker 方式的选项。你不需要两者都做。
1. 创建组织后，你必须通过邀请成员、保护身份验证和强制登录来入驻它。这些步骤相互依赖，因此请按顺序执行。
1. 你可以随时在组织信息变更时更新其基本信息。
