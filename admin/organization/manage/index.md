# 管理组织


作为组织所有者，你可以管理组织的成员资格、访问权限和产品使用情况。你可以邀请成员、将他们分组到团队中、分配或撤销许可与席位，以及更改对 Docker 产品的访问权限。

## 管理您的组织

你从 [Docker Home](https://app.docker.com) 管理你的组织，并且必须被分配
[组织所有者角色](/manuals/enterprise/security/roles-and-permissions/_index.md)。

## 席位与许可

席位和许可都能控制访问，但它们适用于不同类型的套餐。下表总结了两者的区别。

| 授权项 | 授予的内容 | 适用对象 | 管理位置 |
| ----------- | ------------------------------------------------------- | ------------------------------------------------ | ------------ |
| 席位 | 你的 Docker Team 或 Business 订阅中的成员资格 | Docker Core 订阅 | 计费 |
| 许可 | 对特定产品或附加组件的访问权限 | AI Governance、Docker Offload 及其他附加组件 | 成员 |

有关详情，请参阅 [席位](/manuals/admin/organization/manage/manage-seats.md)
和 [许可分配](/manuals/admin/organization/manage/manage-licenses.md)。
