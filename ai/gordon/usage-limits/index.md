# Gordon 用量限制与层级




每个 Docker 账户都包含 Base 层级的 Gordon。付费 Gordon 套餐可解锁更高的用量限制。

## 层级

| 层级  | 用量配额                  |
| ----- | ------------------------- |
| Base  | 任何 Docker 账户均已包含  |
| Plus  | Base 的 2 倍              |
| Max   | Base 的 5 倍              |
| Ultra | Base 的 10 倍             |

有关 Gordon 层级及升级方式的更多信息，请访问 [docker.com](https://www.docker.com/products/gordon)。

## 用量限制

Gordon 的用量以提问数量衡量。你能提问的数量取决于复杂度：涉及更多上下文、文件或 Docker 操作的问题会占用更多额度。

| 层级  | 每 4 小时 | 每天    | 每月    |
| ----- | --------- | ------- | ------- |
| Base  | ~40       | ~100    | ~180    |
| Plus  | ~80       | ~200    | ~360    |
| Max   | ~200      | ~500    | ~900    |
| Ultra | ~400      | ~1000   | ~1800   |

以上为估算值，会随问题复杂度而变化。

用量限制在固定的 UTC 时间重置，而非滑动窗口。4 小时窗口从 00:00 UTC 开始每 4 小时重置一次，每日窗口在 00:00 UTC 重置，每月窗口在每个日历月的第一天 00:00 UTC 重置。

## 查看你的用量

Docker Desktop 会显示用量指示器，让你了解距离额度上限还有多少。若需更多用量，请升级你的层级。
