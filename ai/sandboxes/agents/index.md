# 支持的代理


Docker 沙箱开箱即用地运行以下代理：

- [Claude Code](claude-code/)
- [Codex](codex/)
- [Copilot](copilot/)
- [Cursor](cursor/)
- [Droid](droid/)
- [Gemini](gemini/)
- [Kiro](kiro/)
- [OpenCode](opencode/)
- [Docker Agent](docker-agent/)
- [Shell](shell/) —— 用于手动设置或测试的无代理沙箱

想要预装工具或自定义代理的环境？请参阅[自定义](../customize/)。
