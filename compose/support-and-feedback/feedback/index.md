您可以通过多种方式为 Docker Compose 提供反馈。

### 在 GitHub 上报告错误或问题

要报告错误或问题，请访问 [GitHub 上的 Docker Compose](https://github.com/docker/compose/issues)

### 通过社区 Slack 频道反馈

您也可以通过 `#docker-compose` [Docker 社区 Slack](https://dockr.ly/comm-slack) 频道提供反馈。
