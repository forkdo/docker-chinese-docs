Docker 账户是 Docker 识别你的方式。使用它来访问 Docker Hub 和 Docker Desktop 等产品、管理设置，以及加入组织。

Docker 有两种主要账户类型：个人和组织。你使用个人账户创建并管理组织。有关组织账户，请参阅 [组织](/manuals/admin/organization/_index.md)。有关组织和公司，请参阅 [管理](/manuals/admin/_index.md)。

## Docker ID、邮箱与登录方式

创建账户时，你需要选择一个 Docker ID 和一个登录方式。Docker 还会将一个经过验证的邮箱与账户关联起来。

- Docker 账户：关联你的套餐、Hub 仓库和账户设置。
- Docker ID：标识你的唯一用户名。
- 邮箱：Docker 用于发送通知和安全相关通信的方式。
- 登录方式：邮箱和密码、[单点登录 (SSO)](/manuals/enterprise/security/single-sign-on/_index.md)、Google 或 GitHub。
