了解如何更新你的组织信息。

## 更新组织信息

组织基本信息显示在你的组织落地页上。

这些信息包括：

- 组织名称
- 公司
- 位置
- 网站
- Gravatar 邮箱：要为你的 Docker 账户添加头像，请创建一个 [Gravatar 账户](https://gravatar.com/) 并上传头像。然后，将你的 Gravatar 邮箱添加到你的 Docker 账户设置中。你的头像在 Docker 中更新可能需要一些时间。

要编辑此信息：

1. 登录 [Docker Home](https://app.docker.com) 并从左上角的账户下拉菜单中选择你的
   组织。
1. 选择 **Organization settings**（组织设置）。
1. 输入或更新你组织的信息，然后选择 **Save**（保存）。
