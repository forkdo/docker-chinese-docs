## Docker 计划与账单行为

您的发票历史是您所订阅的 Docker 计划的参考。有关计费周期和续订日期的信息，请参阅 [计划详情](/manuals/subscription/plans/_index.md)。要升级或添加新计划，请参阅 [订阅](/manuals/subscription/_index.md)。
