每当 Docker 套餐订阅续订或发生变更时，Docker 都会开具一张发票。您可以跟踪账户收到的发票，以便随时查看您订阅过的套餐、核对付款状态，并按需下载记录。

## 查看账单历史记录

个人账户和组织账户查看账单历史记录的步骤相同。要查看您的账单历史记录：

1. 登录 [Docker Home](https://app.docker.com/)，然后选择您的个人账户或组织账户。
2. 选择 **Billing**（账单），然后选择 **Invoices**（发票）。
3. 通过以下方式查看单张发票：
   - 选择 **Invoice number**（发票编号）即可在浏览器中打开发票详情
   - 选择 **Download**（下载）即可下载发票副本。

> [!NOTE]
>
> 如果您想查看组织账户的账单历史记录，您必须是组织所有者。

## 理解您的发票

您的发票包含以下信息：

| 发票字段       | 说明                                                   |
| -------------- | ------------------------------------------------------ |
| 发票编号       | 发票的唯一标识符                                       |
| 签发日期       | Docker 生成发票的日期                                  |
| 到期日         | 您的付款截止日期                                       |
| 账单接收方     | 您的账单名称、地址和联系信息                           |
| 明细行         | 订单中每个项目的描述、数量（如适用）、单价和金额       |
| 小计           | 扣除任何折扣之前的金额                                 |
| 总计           | 扣除折扣后的小计，与应付金额一致                       |
| 应付金额       | 您所欠的总金额，以美元计                               |
| 在线支付       | 用于在线支付未付发票的链接                             |

**账单接收方**部分的信息来自您的账单信息。

- 并非所有字段都是必填项。
- 您无法更改已支付或未支付的发票。
- 更新您的账单信息不会更新现有发票。

如果您希望发票中体现不同的账单信息，请在续订日期（Docker 最终确定您的发票时）之前更新账单信息。更多信息，请参阅[更新账单信息](details.md)。

## 查看续订日期

续订日期是按套餐分别设置的，因此如果您订阅了多个套餐，请逐个查看。根据产品的不同，您的账单周期可以是月度、年度或其他节奏。有关特定套餐的续订和账单周期详情，请参阅[套餐](/manuals/subscription/plans/_index.md)。

## 通过发票付款

> [!TIP]
>
> 要使用发票付款，请[升级到 Docker Team 或 Docker Business 套餐](https://www.docker.com/pricing?ref=Docs&refAction=DocsBillingPaymentMethod)并选择年度订阅。

通过发票付款要求在第一个订阅周期使用支付卡或 ACH 银行转账预先付款。续订时，Docker 会向您发送一封发票邮件，让您手动支付，而不是从您的默认支付方式扣款。

- 要将发票付款添加为一种支付方式，请联系您的 Docker 销售代表。
- 您只能在订阅 Docker Team 或 Docker Business 套餐时选择发票付款作为支付方式。
- 发票付款不适用于订阅升级或变更。
