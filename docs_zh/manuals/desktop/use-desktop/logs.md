**日志**视图提供来自 Docker Desktop 中所有容器和最近构建的统一实时日志流。与可从[**容器**视图](container.md)访问的日志不同，**日志**视图让您可以在单一界面中监控和搜索整个环境范围内的日志输出（最多 100 000 条条目）。

## 日志条目

表格视图中的每条日志条目会显示：

| 列            | 描述                                                                    |
| ------------- | ------------------------------------------------------------------------------ |
| **Timestamp** | 该日志行发出的日期和时间，例如 `2026-02-26 11:18:53`。 |
| **Object**    | 产生该日志行的容器或构建。                             |
| **Message**   | 完整的日志消息，包括任何状态码，例如 `[ OK ]`。             |

选择某一行右侧的展开箭头可查看该条目的完整消息。

## 搜索、筛选和导出日志

使用“日志”视图顶部的**搜索**字段来查找特定条目。搜索栏支持：

- 用于精确匹配搜索的纯文本词条
- 正则表达式（例如 `/error|warn/`）

您可以将当前筛选条件保存为预设，以便日后快速访问。预设会记录您的容器选择、构建日志可见性和大小写敏感设置，以及任何生效的搜索词。如果未选择任何容器，预设名称为 all；否则以第一个所选容器命名。

要进一步细化日志流，请在工具栏中选择**筛选**图标以打开容器筛选面板。您可以在此处：

- 勾选单个容器，仅显示其输出
- 勾选 Compose 堆栈，以显示或隐藏整组容器
- 关闭 **View build logs**，以在日志流中排除与构建相关的日志输出
- 使用 **Select all** 或 **Clear container filters** 一次性快速切换所有容器

使用右上角的**导出**按钮（Docker Desktop 4.77 及更高版本可用）导出所有日志，或仅导出与筛选条件匹配的日志。

## 显示设置

在工具栏中选择**显示设置**图标可切换以下选项：
- **Wrap lines**（换行）
- **Show timestamps**（显示时间戳）

您还可以选择 **Clear logs**（清除日志）以从视图中移除日志条目（Docker Desktop 4.79 及更高版本可用）。对话框中提供两个选项：

- **Clear all logs**：立即隐藏所有当前日志条目。
- **Clear logs before**：启用日期和时间选择器。仅隐藏所选时间戳及之前的条目。

清除状态在 Docker Desktop 重启后仍然保留。条目一经清除即无法恢复。
