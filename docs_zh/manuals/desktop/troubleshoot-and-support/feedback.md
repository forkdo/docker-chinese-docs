您可以通过多种方式为 Docker Desktop 或 Docker Desktop 功能提供反馈。

### 产品内反馈

在 Docker Desktop 仪表板的每个视图中，都有一个**提供反馈**链接。点击该链接将打开一个反馈表单，您可以直接通过该表单向 Docker 团队分享您的想法。

### 通过 Docker 社区论坛提供反馈

如需获得社区帮助、查看当前用户主题、加入或发起讨论，请登录相应的 Docker 论坛：

- [Docker Desktop for Mac 论坛](https://forums.docker.com/c/docker-for-mac)
- [Docker Desktop for Windows 论坛](https://forums.docker.com/c/docker-for-windows)
- [Docker Desktop for Linux 论坛](https://forums.docker.com/c/docker-desktop-for-linux/60)

### 在 GitHub 上报告 Bug 或问题

如需报告 Bug 或问题，请访问：
- [GitHub 上的 Docker Desktop 问题](https://github.com/docker/desktop-feedback)
- [GitHub 上的 Docker Extensions 问题](https://github.com/docker/extensions-sdk/issues)

### 通过社区 Slack 频道提供反馈

您也可以通过以下 [Docker 社区 Slack](https://dockr.ly/comm-slack) 频道提供反馈：

- #docker-desktop-mac
- #docker-desktop-windows
- #docker-desktop-linux
- #extensions
