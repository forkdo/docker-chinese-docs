> <a href="https://www.docker.com/pricing/" id="dkr_docs_index_pricing" class="link" rel="noopener">定价页面</a> 以比较套餐。

当您从计费门户前往 Docker 产品目录时，可以自助订阅套餐。套餐可以关联个人或组织账户类型，并包含扩展用量限制的选项。

本节涵盖每个可用套餐的用量权益、计费行为以及套餐管理选项。

要管理您的套餐（添加新套餐或升级活动套餐），请参阅 [管理套餐](/manuals/subscription/manage.md)。
